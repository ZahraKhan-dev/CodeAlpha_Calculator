 CodeAlpha_Calculator

A Responsive Calculator built using HTML, CSS and JavaScript for the CodeAlpha Frontend Development Internship Task 2.

 About Project
This project is a fully functional, responsive calculator that works on both desktop and mobile devices. It performs basic arithmetic operations with a clean and modern UI.

This was created as part of my internship task at CodeAlpha.

 Features
- Responsive Design: Works perfectly on mobile, tablet and desktop
- **Basic Operations: Addition, Subtraction, Multiplication, Division
- Clear & Delete: `AC` button to clear and `DEL` to delete last digit
- Modern UI: Clean design with CSS3 styling and hover effects
- Real-time Calculation: Uses JavaScript for instant results
- User Friendly: Large buttons for easy use

 Technologies Used
- HTML5 → Structure of the calculator
- CSS3 → Styling, layout, responsive design, animations
- JavaScript → Logic, calculations, button functionality
